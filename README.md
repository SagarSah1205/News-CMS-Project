# News-CMS-Project
Content Management System – News Blog Website

A full-stack Content Management System (CMS) developed using the MERN Stack (MongoDB, Express.js, React.js, and Node.js). The system provides a platform for managing and publishing news articles through a user-friendly interface.

The website allows users to browse news articles by category, view detailed posts, and interact with the available content. Administrators/editors can manage news content, categories, users, and website settings through the management system.

Key Features
User registration and login
News/article creation and management
Category-based news organization
Article editing and deletion
Editorial calendar for content planning
Responsive and user-friendly interface
Admin/editor content management
MongoDB database for storing application data
Authentication and role-based access
Website settings and content management
Technology Stack
Frontend: React.js, HTML, CSS, JavaScript
Backend: Node.js, Express.js
Database: MongoDB
ODM: Mongoose
Development Tools: Git, GitHub, npm
Project Objective

The main objective of this project is to develop a centralized platform that simplifies the process of creating, organizing, managing, and publishing news content while providing users with an easy way to access categorized news and articles.

This project demonstrates practical implementation of full-stack web development, database management, authentication, CRUD operations, and content management using the MERN stack.
